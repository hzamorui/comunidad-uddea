# Comunidad UDDEA · Equipo 09

Prototipo del **Reto UAXMaker U-Lab UDDEA 2026**: una comunidad digital especializada para profesionales del fútbol (directores deportivos, scouts, analistas, entrenadores), que aporte más valor que las plataformas generalistas e incluya el fútbol femenino.

## Cómo trabajamos

1. Toda tarea es una issue creada con una plantilla: *investigación o gestión*, *desarrollo* o *error*.
2. Cada issue tiene responsable, etiqueta de rol y sprint (S0–S3 en la fase de investigación).
3. Flujo: **Backlog → Por hacer → En curso → Revisión → Hecho**. Máximo 2 tareas en curso por persona.
4. Nada pasa a *Hecho* sin que lo revise alguien de la otra carrera.
5. El código entra en `main` mediante pull request, enlazado a su issue (`Closes #12`).
